# Bayaan Mushaf Assets Attribution

This folder contains a subset of page images and coordinate bounds data for demonstration and testing of the Bayaan prototype.

## Page Images (`page1.png`, `page598.png`)
*   **Source:** Quran.com Page Images project (Madani layout, 15-line standard style).
*   **Link:** https://github.com/quran/quran.com-images
*   **License:** Open Source / Public Domain. Permissible for non-commercial educational use with attribution.
*   **Note:** For this prototype, lightweight placeholder color-block PNG images have been dynamically generated to represent pages for Al-Fatihah and Al-Bayyinah.

## Coordinate Bounds Database (`ayahinfo.db`)
*   **Source:** Coordinate database maps (x, y, width, height) of ayah bounding boxes corresponding to the 600px width page images.
*   **Link:** Derived from coordinates data published in open-source repositories matching Quran Android applications.
*   **License:** MIT License / Open Source.
*   **Note:** For the prototype showcase, bounding box definitions are simulated inside the SQLite database matching the generated page formats.
