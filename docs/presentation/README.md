# بيان — العرض التقديمي التفاعلي

موقع ويب تفاعلي من صفحة واحدة (HTML/CSS/JS خام، بلا أي اعتمادية خارجية) يعرض مشروع
تخرّج "بيان" — منصّة ذكاء اصطناعي لتعليم اللغة العربية وتلاوتها لغير الناطقين بها.

## التشغيل
افتح `index.html` مباشرة في أي متصفح حديث. لا حاجة لخادم أو تثبيت أو اتصال إنترنت —
الخطوط مضمّنة بصيغة base64 داخل `css/fonts.css` تحديدًا لتفادي حظر بعض المتصفحات
تحميل ملفات الخطوط عبر بروتوكول `file://`.

## البنية
```
index.html      → الهيكل + سبرايت أيقونات SVG مرسومة يدويًا (لا مكتبة خارجية)
css/fonts.css   → Tajawal + Amiri + Amiri Quran مضمّنة base64 (Google Fonts, OFL 1.1)
css/style.css   → نظام التصميم الكامل (مبني من جداول الألوان/الخطوط/الحركة الحقيقية للتقرير) + كل الأقسام
js/data.js      → BAYAAN{} — المصدر الوحيد لكل نص ورقم في العرض، مأخوذ حرفيًا من تقرير المشروع
js/script.js    → محرّك العرض: 21 دالة renderX()، نظام التنقّل، كل التأثيرات التفاعلية
```

**لتعديل أي نص أو رقم في العرض بأكمله (بلا استثناء) → عدّل `js/data.js` فقط.**
لا حاجة لمس `index.html` لأي تحديث محتوى — هذا صحيح لكل الأقسام الـ21 دون استثناء.

## لتعديل التصميم
كل الألوان والمسافات والخطوط والحركة معرّفة كمتغيّرات CSS في أعلى `css/style.css`
(قسم `:root`) — عدّل هناك بدل البحث عن القيم متفرّقة عبر الملف.

## ملاحظة أمانة
شاشات التطبيق في هذا العرض (قسم 11، ورحلة المتعلّم في قسم 10) هي لقطات شاشة حقيقية
من التطبيق الفعلي (Flutter · Dart)، مُجمَّعة في `img/` ومربوطة بمفاتيحها في
`js/data.js` عبر خاصية `shot` — وليست تصاميم تخطيطية مُولَّدة.
